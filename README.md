# 采风 StyleScout

把遇见的好 UI 留下来，再改成自己的样子。

**在原网页看到喜欢的按钮或卡片，可以只收藏这一块，之后随时打开改字、换色。**

[下载采风 0.9.0 Windows 预览版](https://github.com/Charlesstillalive/stylescout/archive/refs/heads/release/v0.9.0.zip)

## 第一次使用

1. 电脑需装有 Chrome 或 Edge，以及 [Node.js 22 或更新版本](https://nodejs.org/)。
2. 下载并完整解压，双击 **启动采风.cmd**，让素材库保持打开。
3. 想先试一张卡片，可以在素材库填入公开网页地址，展开 **只收藏一张卡片或一个按钮**，填写卡片标题或按钮原文，点 **只收藏这一块**。出现重名提示时，换成该卡片独有的一句原文。
4. 收藏成功会打开编辑页。点卡片上的文字，选 **只改这段文字**，也可以直接在左侧选标题。改完点 **保存修改**。以后从素材库点 **打开修改** 即可继续。

## 在原网页点选收藏

在 Chrome 或 Edge 的扩展管理中开启开发者模式，选 **加载已解压的扩展程序**，选择解压后的 **browser-extension** 文件夹。第一次把素材库和原网页放在同一个浏览器里打开。

在原网页右键选 **用采风选一块收藏**，鼠标移到喜欢的卡片，确认蓝框后点一下。按 ↑ 扩大一层、↓ 缩小一层、Esc 退出。收藏后点 **打开素材** 就能改。也可以从采风扩展图标开始选。

如果你同时开着几个不同的采风素材库，先在目标素材库点一次采风扩展，指定收藏位置。部分跨域图片、背景图或网页字体可能缺失，请对照原网页检查。

## 连接 ChatGPT 桌面版

需要支持本机插件的桌面客户端及可用的 `codex plugin` 命令。不同账号、客户端版本的插件入口可能不同；普通 ChatGPT 网页版目前不能直接连接这个本机版本。

已具备上述条件时，在解压后的文件夹双击 **安装桌面插件.cmd**。安装结束后重新打开桌面客户端，开启新对话，用 **@** 选择 **采风 StyleScout**，发送：

> 打开我的素材库。

想通过批注收藏时，在 ChatGPT 自带浏览器里标出卡片，发送「@采风 收藏这张卡片」。采风会根据对话提供的网址和标题重新访问公开网页。已验证能按标题保存卡片；批注发出后是否能自动带齐这些信息，还需要在真实新对话里验证。登录后才能看到的卡片，建议在已经打开的原网页用扩展点选。

也可以在命令行安装：

```powershell
codex plugin marketplace add Charlesstillalive/stylescout
codex plugin add stylescout@stylescout
```

如果电脑提示找不到 `codex`，仍可直接运行独立素材库；请先确认自己的桌面客户端是否支持本机插件及配套命令，不要将“下载了文件”视为“已连接 ChatGPT”。

## 第一次改造

收藏一个区域后，点 **交给 ChatGPT 修改**，填写要求并点 **复制素材和修改要求**。打开 ChatGPT 桌面版，新建对话，输入 **@** 选择 **采风 StyleScout**，再粘贴并发送。例如：

> 把这张卡片改成粉蓝色，标题改为“我的工作室”，保留排版，另存一份。

ChatGPT 读取素材后修改文字或样式，保存成新收藏。等 ChatGPT 回复新版本名称，回采风点 **回素材库找新版本**，搜索该名称并打开。

**修改图片里的人物**需要 ChatGPT 自身的图片编辑能力。采风只负责读取原图和保存结果，不自带图片生成服务。若客户端不能把生成图片交回插件，请下载图片，再用编辑页提供的上传另存入口。动图改成静态图片后不会自动保留表情动画。

## 能做什么，哪些有边界

| 功能 | 当前情况 |
|---|---|
| 收藏整页、单独收藏按钮/卡片/区域 | 可用；保存元素结构、样式及可下载的图片、字体 |
| 修改文字、颜色、字号、圆角、尺寸等 | 可用；支持预览、保存和重新打开 |
| ChatGPT 读取素材、元素及预览 | 已实际调用验证 |
| ChatGPT 修改文字/样式并另存 | 保存与原版保留已通过本机检查 |
| 图片生成和自动回传 | 依赖宿主能力；原生生成文件自动回传链路仍待进一步验证，支持手动上传另存 |
| 还原原网站 | 保留采集尺寸下的静态画面，不复制网站业务、登录状态、视频或完整交互 |
| 所有网站都能采集 | 不保证；登录、反爬、访问限制、特殊渲染和部分外链资源可能导致失败或差异 |
| 手机、Mac、Linux、ChatGPT 网页版 | 未完成支持与验收，本版以 Windows 本机为准 |

收藏后的素材不是单张截图；截图用于对照，实际修改使用提取到的元素。截图内的人物、插画等仍是图片，不能当作文字元素修改。

## 数据与隐私

- 默认保存在用户目录的 `.dsh/style-scout` 中；目录名称沿用旧版，程序不依赖 DSH。升级或重装前建议备份该文件夹。
- 公开包不包含任何人的素材库、浏览记录、登录信息或密钥。
- 服务只监听本机地址。采集时会访问你输入的网站及其图片、字体等资源；用 AI 改造时，选中素材及要求会提供给所用的 AI 客户端。
- 采集使用独立浏览器环境，不继承日常浏览器的登录状态。
- 公开发布或商业使用收藏素材前，请自行确认来源授权。

## 常见问题

**提取失败 / Failed to fetch**：从“启动采风.cmd”重新打开素材库，确认原网址可访问；不要继续使用旧端口的收藏地址。若仍失败，换一个无需登录的页面测试。

**收藏后排版不同**：先检查是否有采集警告，等待原站加载完成后重试。某些动态效果、嵌入内容或远程资源无法完整保留。

**提示已有采风运行**：使用已打开的素材库；如果此前使用旧 DSH 适配，请先正常退出旧服务，避免同时写入同一份素材库。

**ChatGPT 找不到采风**：安装后重新打开桌面客户端并新建对话，在 @ 菜单选择插件。安装完成和当前对话已加载是两件事。

## 源码和检查

`plugins/stylescout/server/lib` 是独立版的可读源码，无需额外构建，也没有需要下载的 npm 运行依赖。`plugins/stylescout/skills` 是插件使用说明，根目录市场文件负责安装发现。

```powershell
npm run check
```

检查会使用临时素材库验证独立启动、另存、原版保留、图片保存、冲突和坏图拒绝、重启恢复、备份与工具调用，需要本机 Chrome/Edge。不会向你的正式素材库添加测试收藏。

反馈问题请到 [Issues](https://github.com/Charlesstillalive/stylescout/issues)，附上操作步骤和错误提示；不要上传自己的素材库、密钥或登录数据。
